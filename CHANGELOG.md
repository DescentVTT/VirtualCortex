# Changelog

All notable changes to this repository are documented here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/). Crate versions follow [Semantic Versioning](https://semver.org); the architecture whitepaper carries its own version in its front matter.

This file is a historical record: `spec-graph` treats it as history, so nothing written here is an obligation.

## [Unreleased]

### Added

- **Fourteen state crates (ADR-0016, proposed; the workspace has thirty-two).** `cortex-thalamus` (relay gate: tonic, burst, closed), `cortex-linguistic` (the three-layer native language record: construction-grammar frames over vector-symbolic roles with a Q16.16 linear recurrent cell for prosody; no external language model), `cortex-tools` (brokered tool-invocation frames with a five-state machine), `cortex-attention` (saccade and fixation), `cortex-affect` (allostatic load, comfort, mood), `cortex-autonomic` (voltage, temperature, power limits and cut flags), `cortex-spatial` (path integration with a wrapping heading and a landmark fix), `cortex-curiosity` (novelty decay and urgency), `cortex-social` (empathic resonance and asymmetric trust), `cortex-ethics` (deontological veto: imperative, harm, authorization, benefit never overrides), `cortex-knowledge` (consolidated affordances and hazard), `cortex-reasoning` (AND / OR / NOT / IMPLIES rule nodes), `cortex-arithmetic` (checked 128-bit and Q16.16 opcodes with error flags), `cortex-imagination` (sandboxed rollout frames). Each is a 64-byte `#[repr(C, align(64))]` record with a compile-time assertion, one deterministic saturating rule and four to nine boundary tests (75 new tests; 145 in all). Two width defects and one layout defect in the proposal were corrected on the way in: Q16.16 fields are 32 bits, and 128-bit operands are `u64` low and `i64` high words rather than tuples. The maintainers moved three boundaries to admit them: whitepaper §1.5 puts a brokered digital environment and a language model in scope, §8.10 adds a tool-broker process outside the worker seccomp filter, and §8.9 adds the veto gate and the vitals flags in front of the watchdog. The record also states the six-part admission test the next crate must pass, and the responsibilities of `cortex-sensory`, `cortex-homeostasis`, `cortex-agency`, `cortex-executive`, `cortex-symbolic` and `cortex-hippocampus` are narrowed so that every quantity keeps one owner. Whitepaper §1.6, §3, §5, §6.8, §6.9, §8.8 to §8.10, §11.1, §12 and Appendices A, C and D, the README, `CLAUDE.md`, `CONTRIBUTING.md` and the reader's guide follow; the member-count assertions move from 18 to 32 and fourteen test-module assertions and fourteen record assertions are added. The image format version is unchanged: no existing record changed, and the new arenas get sections when the loader exists (milestone M4).
- **Briefs 004–008** for the remaining open findings: 004 cerebellar delay line (F-8), 005 timing-wheel geometry and drain (F-11), 006 the first benchmark harness and protocol (F-13), 007 a test for every public function (F-14), 008 embodiment frame rings (F-17). Each carries a spec-guard precondition directive, so a brief whose defect is fixed without archiving it fails CI. F-5 is not a brief: it is ADR-0009's decision.
- **`CLAUDE.md`**: the switchboard for coding agents — eight principles, the code invariants, a reading map and the exact command set CI runs.
- **`briefs/`**: numbered, self-contained prompts for rounds of work, with a README defining the mandatory sections and the archive procedure; three seed briefs (001 saturating arithmetic, 002 `no_std` and derives, 003 synaptic weight Q-format); `scripts/check-briefs.mjs` enforces the sections and runs as `npm run spec:briefs` locally and in CI. Live briefs are also read by `spec-guard` (precondition directives) and `spec-graph` (deliverables as obligations).

### Changed

- **Whitepaper 4.0.0.** The architecture document describes the thirty-two-crate workspace of ADR-0016; its structure, labels and rules are unchanged from 3.0.0, and every new claim about the tree carries an executable assertion.
- **Finding F-5 closed; ADR-0009 accepted.** The workspace is edition 2024 with `rust-version = "1.85"`, both inherited from `[workspace.package]` by all nineteen manifests; `cargo fix --edition` changed no source file and rustfmt's 2024 style edition reordered `use` lists in five files. The workspace resolver is 3 (MSRV-aware). `rust-toolchain.toml` pins the toolchain CI and contributors build with at 1.97.1; a new CI job `msrv` builds and tests on the `rust-version` read from `Cargo.toml`. The timing wheel's `#[allow(clippy::manual_is_multiple_of)]` is gone: clippy reads the MSRV. Whitepaper TC-8 is Implemented and MUST, held by three executable assertions; the README badge says Rust 1.85+.
- **Finding F-17 narrowed (brief 008 executed, ADR-0015).** `cortex-embodiment` gains the frame ABI and the ring protocol: `TorqueFrame` (epoch, twelve Q16.16 torques) and `JointStateFrame` (epoch, twelve Q16.16 positions; velocities are the consumer's finite difference), both 64 bytes; rings of 16; `EmbodimentRingBuffer` carries `abi_version` and `capacity` in its former reserved bytes and exposes `producer_claim`/`producer_publish`/`consumer_peek`/`consumer_release`, index-only with acquire/release on the cursors and no `unsafe`; `heartbeat_ms` is the producer's monotonic clock at publish. Eight tests including a two-thread exchange of 100 000 frames. The mapping, the 1 ms loop and the torque decoder remain Specified. Brief 008 is archived; no live briefs remain.
- **Finding F-14 closed (brief 007 executed).** Every state crate now carries a `#[cfg(test)]` module and every public function and associated constant has at least one test: `cortex-symbolic` (`bind` stores the pair, sets bit 0, preserves the other flag bits, is idempotent, touches nothing else; `DIMENSIONS`), `cortex-sensory` (a stub driver fills the caller's slice through `dyn SensoryPeripheral`, never exceeds it, is `Send + Sync`; `Default`), `cortex-embodiment` (`new` and `Default` all-zero; independent atomics), `cortex-fabric` (`MAGIC`), and layout tests for `cortex-neuromod`, `cortex-hippocampus` and `cortex-telemetry`. Eighteen `spec-guard` directives in whitepaper §1.6 hold one test module per crate; `CONTRIBUTING.md` states the per-item rule as a review rule. Brief 007 is archived.
- **Finding F-13 narrowed (brief 006 executed, ADR-0014).** A nineteenth workspace member, `benches/cortex-bench` (`publish = false`), benchmarks the existing components of target T-3: wheel schedule and advance on the production geometry, `synaptic_efficacy_q16`, `compute_gating`, `step_ignition`, all from a fixed-seed LCG. The harness is **criterion 0.7.0**, pinned exactly with default features off, the workspace's only third-party dependency and a dev-dependency of that crate alone; `Cargo.lock` gains 43 dev-only packages; the state crates' dependency tables stay empty. `docs/benchmarks/README.md` defines an admissible run (reference platform, isolated core, fixed frequency, `perf stat`) and the results convention with an `admissible:` line; the first recorded run, from a Windows developer machine, is marked not admissible and no figure enters §10.2. CI executes the benchmarks once per run and asserts no timing. Brief 006 is archived.
- **Finding F-11 closed (brief 005 executed, ADR-0013 amends ADR-0004).** `FlatTimingWheel<CAP>` has 256 fine slots (10 µs, 2.56 ms) and 256 coarse slots (100 µs, 25.6 ms), both powers of two; each slot is a fixed-capacity list of opaque 28-bit tokens, with the fine residual packed into coarse entries. `schedule(delay, token)` rejects zero delay, delays at or beyond 2 560 ticks, oversized tokens and full slots without mutating the wheel; `advance()` clears the consumed slot, cascades the coarse window that begins at the new tick, and returns the due slot in a deterministic order (fine-scheduled tokens, then cascaded tokens, each group in scheduling order). `WorkerWheel = FlatTimingWheel<2048>` is 4 195 336 bytes (asserted); the capacity model's row 19 falls from 512 MB to 268.5 MB. `schedule_fine` and the lane masks are gone. Eight tests. Brief 005 is archived.
- **Finding F-8 closed; image format version 3 (brief 004 executed).** `CerebellarMicrozone`'s 32 reserved bytes became a seven-slot delay line (`pred_ring`) and a packed control word (`delay_ctl`: head, plant delay, filled count, command-sign bitmap). `step_forward_model` now predicts the observation `d` steps ahead through a learned gain, compares the observation arriving now with the prediction made `d` steps ago, adapts the gain by `sign(u) · round(error / 16)` (rounding, not flooring, so the residual is bounded by half a learning step), and returns the predicted change as the Purkinje output. `set_plant_delay` (clamped to 7; 0 disables learning), `plant_delay`, `filled` and `MAX_PLANT_DELAY` added. Seven tests, including convergence on the plant `y(t+d) = y(t) + k·u(t)` to within 8 LSB after 400 steps for three `(k, d)` pairs and for an alternating-sign command. Brief 004 is archived.
- **Findings F-3 and F-12 closed; image format version 2 (brief 003 executed, ADR-0012).** Sixteen-bit synaptic base weights are Q1.15: `SynapseBlock::weights_q16` is renamed `weights_q1_15`, and `cortex_core::synaptic_efficacy_q16` implements the widening product with the Q0.8 short-term-plasticity factors (exact `i64` product, one shift by 15, floor toward negative infinity) with seven unit tests. `AgentPerspectiveState::intention_vector_ptr` is renamed `intention_vector_idx`. `CortexFileHeader` gains `MAGIC` and `FORMAT_VERSION = 2`; the byte layout is unchanged, the meaning of the weight bytes is not, so version-1 images are refused. Brief 003 is archived.
- **Findings F-6 and F-7 closed; TC-6 Implemented (brief 002 executed).** All eighteen crates are `#![no_std]` (fourteen gained the attribute; none used a `std` item). Every record without atomics derives `Clone, Copy, Debug, PartialEq, Eq`; `DendriticSuperNeuron` and `EmbodimentRingBuffer` (control records) and `FlatTimingWheel` (a 2 248-byte per-worker value) derive `Debug` only, each with a comment citing whitepaper rule L-5. TC-6 and L-5 are now MUST, and an executable assertion holds the `no_std` count at 18. No `Pod` dependency was added: the choice between `bytemuck` and `zerocopy` is deferred until the image loader needs it. Brief 002 is archived.
- **Finding F-4 closed; F-14 narrowed (brief 001 executed).** `compute_gating`, `step_forward_model` and `step_ignition` use saturating arithmetic; `update_circadian_tick` uses `wrapping_add` before its 16-bit mask, wrap being the intended semantics of a phase counter; `evaluate_threat` performs no arithmetic and was left as is. Each of the five functions gained boundary tests (twenty-two in total) that fail under plain arithmetic in a debug build. `FlatTimingWheel::schedule_fine` and `SymbolicHypervectorHeader::bind` remain untested. No Q16.16 newtype was proposed: five call sites do not justify one yet. Brief 001 is archived in `briefs/archive/`.
- **Findings F-9 and F-18 closed.** Crate metadata (`version`, `edition`, `authors`, `license`, `repository`) is inherited from `[workspace.package]`; each manifest keeps only `name` and `description`, and all eighteen now carry one. `cortex-sensory` gained the compile-time assertion that `SensoryEvent` is 8 bytes, 8-aligned; the whitepaper's assertion-block directive now requires 18.

- **Finding F-10 closed.** All crates formatted with `rustfmt` (whitespace and comment alignment only). `Default` implemented for `FlatTimingWheel` and `EmbodimentRingBuffer`, delegating to their `const fn new()`; `FabricPacketHeader::MAGIC` written as a byte-string literal. `cargo fmt --check` and `cargo clippy -D warnings` are now blocking in CI; the two advisory steps and their `continue-on-error` are gone.

- **Whitepaper 3.0.0.** Rewritten on the arc42 template with C4 views. Every claim now carries a status label (Implemented, Specified, Target, Hypothesis). Record layouts are transcribed from source with byte offsets. All performance figures are Targets with measurement protocols; the figures previously stated as results ("P99.99 < 35 ns", "> 120 M spikes/s", "< 100 ms cold boot") are withdrawn. The founding five axioms (virtual existence, state/compute decoupling, turn invariant, discrete delay, metabolic tiering) are restored as the solution strategy. Findings F-1 to F-17 record every disagreement between the previous specification and the tree.
- **README** rewritten to describe the repository as it is: a state-model-stage workspace, with a status table and a crate table.
- **Traditional Chinese document** replaced by a reader's guide (`docs/zh-TW/README.md`) that carries no layouts or figures, per ADR-0008. The former full translation (`docs/zh-TW/architecture-report.md`) is removed.
- **Documentation tools bumped**: `@descent-vtt/spec-guard` 0.4.0 → 0.5.0 (an assertion whose scope holds no files now fails instead of passing vacuously; import assertions read Rust; SARIF output) and `@descent-vtt/spec-graph` 0.2.1 → 0.3.0 (0.2.2 fixed the defect found in this repository where a link to a file holding a register resolved to its last row, so anchored links into the whitepaper were reported broken; 0.2.3 reports a path that names two files as ambiguous instead of binding it to whichever was indexed last; 0.3.0 reads reference-style links and both spellings of every front-matter relation). No directive or configuration changed; 66 assertions and the graph pass on both versions.

- Struct definitions reproduced in the previous whitepaper did not match the source for 15 of 19 types, including one 72-byte record described as 64 bytes. Replaced with tables transcribed from `crates/`.
- The README referred to a documentation checker by an absolute path on one developer's machine.

### Removed

- The claim of a "Rust 2026 edition"; no such edition exists. Edition policy is now ADR-0009 (proposed).
- The "Sovereign", "Grand", "Monumental" and "Fidelity 5.0/5.0" vocabulary and the "conscious" description of the workspace subsystem.
