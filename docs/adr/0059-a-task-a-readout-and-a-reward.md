# ADR-0059: A task, a readout and a reward — the runtime composes a two-alternative task on the executor: a stimulus drawn from the trial's index and a seed, a readout that counts a trial's spikes per set from the executor's own train and selects through `cortex-basal-ganglia`'s gating rule, and a reward whose sign is the outcome's; the harness's state is the caller's and the image format stays 14

## Context and Problem Statement

The tree held every piece of a reward loop and had never run one. [ADR-0032](0032-three-factor-plasticity.md) put the pairing amount into an eligibility trace per synapse and let the modulator consolidate a fraction of it at the presynaptic spike; [ADR-0027](0027-vocal-synthesis-and-computational-humor.md) and `Executor::reward` made a reward-prediction error an input between ticks; [ADR-0050](0050-the-train-inside-the-executor.md) gave the executor its own spike train, the same on every worker count; [ADR-0044](0044-reference-network.md) gave a network to run on and a drive that is a function of the tick. What was missing was the composition: a stimulus, a behaviour read out of the train, and a reward that depends on the behaviour. `cortex-basal-ganglia`'s `compute_gating`, the rule the crate that owns action selection carries ([ADR-0016](0016-thirty-two-crate-architecture.md)), was composed by nothing: `grep -rn compute_gating runtime/` found nothing and the runtime's manifest did not name the crate, while whitepaper §1.6 listed the rule in its Logic column.

Brief 027 asked for one module that composes what exists and invents nothing: a stimulus that is a function of the tick and a seed, so that the whole run is an input trace (§8.3); a readout whose selection is `compute_gating`'s, the runtime writing only the drives; a reward the caller passes to `Executor::reward` between trials, inside the trace's window; refusals for every configuration that would be mis-read or would silently do nothing; and the state of the harness (the trial's cursor, the counts, the channels) on the caller's side, with the consequence stated as debt. What the composition measures is [ADR-0060](0060-the-reward-path-measured.md)'s.

Two facts of the modulator shaped the design. `modulation(baseline)` is `clamp(baseline + dopamine, 0, 1)` and there is no anti-Hebbian reversal: a punishment can withhold a pairing's consolidation but never reverse it, so the reward's whole effect is the *fraction* of each pending trace that a presynaptic spike consolidates. And at a baseline of 1.0 every pairing consolidates in full and a positive reward adds nothing, since the clamp is already at the ceiling; a reward-gated run needs a baseline strictly inside the interval, and a task that would deliver a reward at the ceiling is a configuration that silently does nothing.

## Decision Drivers

- [ADR-0016](0016-thirty-two-crate-architecture.md): every quantity has one owner. The selection is `cortex-basal-ganglia`'s, the modulation `cortex-neuromod`'s, the trace and its consolidation `cortex-core`'s, the train and the composition the executor's. No new crate; no new rule.
- §8.3: a run is `(image, seed, input trace)`. A stimulus drawn from the trial's index and a seed by `mix64`, as `Drive` draws units from the tick, is an input trace as a rule; a reward whose sign is the outcome's is a function of the run so far, and a run that replays its rewards at the same ticks is the same run.
- [ADR-0023](0023-executor.md) and [ADR-0050](0050-the-train-inside-the-executor.md): the train is bit-identical on every worker count, so a readout over it is, and so is the whole run; the round exercises this and does not re-prove it.
- Principle 5: a mis-read refused at construction beats one detected in a reading. A trial whose spikes exceed the train's capacity would be silently mis-counted; the bound a unit's refractory window puts on a trial's spikes is a rule of `cortex-core`, so the refusal is exact.
- No record changes and the format stays 14: the harness's state is the caller's, as [ADR-0043](0043-discovery-path.md)'s affect state was the caller's until [ADR-0052](0052-the-term-arena-in-the-image.md) moved it in.

## Considered Options

1. **A runtime module `task.rs`: `Set`, `Stimulus`, `Readout` over two `BasalGangliaChannelState`s, `Feedback`, `Task::trial`, with the refusals named; `cortex-basal-ganglia` a path dependency of the runtime.**
2. The readout as a third `Drive`-like rule in `cortex-connectome` or a new field of the homeostasis record.
3. The task's cursor and counts as a section of the image, resumable.
4. A selection written in the runtime (the sign of the count difference) without the crate's rule.

## Decision Outcome

Option 1; the runtime gains one path dependency on a workspace crate, as [ADR-0043](0043-discovery-path.md) gained three; `npm run spec:deps` allows it for the runtime and for no state crate.

- **The sets and the stimulus.** `Set { first, len }` is a contiguous set of units with `end` (widened to `u64`), `contains` and `overlaps` (an empty set shares no unit). `Stimulus { set, messages, efficacy_q16 }` injects `messages` basal messages of `efficacy_q16` into every unit of its set through the executor's injector, between ticks before a trial's first tick, and returns how many it injected; an injector that refuses one stops it there, as `Drive::step` stops. Two messages of 1.25, the replay drive's of [ADR-0038](0038-episodic-ledger-and-replay.md), fire a unit at its base threshold exactly once, about twelve ticks on. Which of the two stimuli a trial presents is the low bit of `mix64(seed ^ trial)`, so the sequence is a function of the seed and the index, the same on every run and every worker count.
- **The readout.** `Readout::new([Set; 2])` holds the two sets and two `BasalGangliaChannelState`s at rest with ids 0 and 1. `count(train, start, ticks)` counts the trial's spikes per set from a tick-ordered train read at the trial's end, scanning from the newest entry back to the first one before the trial and stopping (a wrapping difference against the start, §8.4); the contract, that the slice holds nothing after the trial, is the executor's train's when it is read where `Task::trial` reads it, and a test states it. `select(counts)` writes each channel's own count into `striatal_d1_drive` and the other's into `striatal_d2_drive`, both as Q16.16 (`count × 1.0`, saturating at the width), `stn_hyperdirect_drive` zero, and calls `compute_gating` on both: the channel whose count exceeds the other's is selected, and neither at a tie (the crate's own rule: a net output of exactly zero is not a selection). Two selections or none is no selection. The dopamine-scaled D1/D2 balance and lateral inhibition stay Specified; the runtime writes the drives and nothing else.
- **The task.** `Task { stimuli: [Stimulus; 2], readout, drive, ticks, seed, reward_q16, mirrored, feedback }`, every field the caller's. `answer(s)` is `s` or, mirrored, the other readout. `Feedback::Answer` signs the reward by the outcome (a tie is an error); `Feedback::Shuffled` signs it by a coin, bit 32 of the same `mix64` draw, the stimuli unchanged, so the same total dopamine carries none of the information; `Feedback::Withheld` calls `reward` not at all. `trial(exec, index)`: the trial's stimulus injected, `ticks` ticks each under the background drive (`Drive::step` then `Executor::tick`), the train read once, the selection, `Executor::reward(±reward_q16)` between ticks, and an `Outcome { trial, stimulus, counts, selection, correct, reward_q16, signal_q16 }`. The reward reaches the modulator before the next trial's first tick, so every pairing of the trial is inside the eligibility window whatever the trial's length below $2^{16}$ ticks, and the dopamine window of $2^{14}$ ticks reaches the next trials' presynaptic spikes, where the consolidation happens.
- **The refusals** (`TaskError`, checked by `check` against the executor and again by every `trial`): `NoStimulus` (a stimulus with no message), `EmptySet`, `SetOutsideArena`, `SetsOverlap` (any two of the four), `NoTicks`, `TrainTooSmall` (the train's capacity below `units × spikes_per_unit(ticks)`, where `spikes_per_unit` is one per `MIN_INTERVAL_TICKS`, the shorter of the two refractory windows of `cortex-core`, 50 ticks, the last interval counted whole; a unit integrates nothing inside its window, so it cannot fire twice within it), `CountBeyondWidth` (a readout set whose count could reach `i16::MAX`, where two saturated drives would tie), `NegativeReward` (the sign is the outcome's, never the constant's), `NoReward` (a magnitude of zero with feedback that would deliver it), `RewardAtCeiling` (the baseline at 1.0 with feedback that would deliver a reward: the positive half does nothing there), and `Inject` (the injector's refusal of a stimulus or drive message, the trial stopped there). A trial refuses before it injects anything.
- **Tests** (`task.rs`): every refusal by name, at its edge where it has one (the train's bound one refractory window either side; the width at 32 767 and 32 768 units at one spike each and at two); a trial with every readout spike in one set selects that set, with the channels' four fields as `compute_gating` leaves them; the tie of nothing and the tie of four and four; the counts of a hand-built train across the tick wrap, with entries before the trial excluded and the contract stated; the selection as the sign of the difference and its saturation; the reward's sign and magnitude at the modulator after a correct and an incorrect trial against an oracle `NeuromodulatorState` that replays the reward and every tick's decay, the shuffled sign from the coin and the withheld signal at rest; the same outcomes on one worker and on four; the stimulus and the coin as fair, distinct functions of the seed; a stimulus stopped where the ring refuses. The lattice property over `testkit/prop.rs`: over seeded tick-ordered trains and seeded set pairs the counts are the filter's and the selection is the sign of the difference, none exactly at equal counts, and the same on the lattice of counts within the width.
- **What the module does not own.** No constant of a task: the sets, the trial's length, the reward's magnitude, the baseline and the seed are the caller's, written by the measurement that uses them ([ADR-0060](0060-the-reward-path-measured.md)). No reward predictor: the reward-prediction error is the outcome's sign times the caller's constant, and `cortex-predictive` stays composed by nothing. No rule that maps a symbol to a pattern of units (H-11's synaptic half): the stimulus is a set, not an id.
- **Accepted debt.** A learning run is not resumable from an image: the trial's cursor, the counts and the two channels are the caller's, so an image written between trials resumes the network and the modulator but not the task's position. The precedent is [ADR-0043](0043-discovery-path.md)'s affect state, the caller's until [ADR-0052](0052-the-term-arena-in-the-image.md) moved it in with a format bump; a task that needs to survive an image is that round's decision, with §5.2's table and the image tests.

### Consequences

- Good: the reward path is closed for the first time on a behaviour the engine reads back, by composition alone; the crate that owns action selection is composed; every configuration that would be mis-read or would silently do nothing is refused by name.
- Good: a run is an input trace: the stimulus sequence, the coin and the rewards are functions of the seed, the index and the train, so a run is the same on every worker count and architecture, and a measurement over it can be pinned.
- Neutral: the runtime's dependency list grows by one; the count directive in whitepaper §5.1 names it.
- Bad: the debt above; and a two-alternative task with a global scalar reward can separate only synapses whose traces differ (Legenstein, Pecevski and Maass 2008), which is why the stimuli are disjoint sets and one trial holds one stimulus, and why the measurement's controls are what they are.

## Alternatives considered and why rejected

- **Option 2**: a readout is a composition, not a quantity; no record owns it and a field would name what the caller does.
- **Option 3**: a section of the image for a harness whose first measurement may say the loop does not move the behaviour; the debt is stated, with the precedent and the round that would pay it.
- **Option 4**: the sign of a difference is `compute_gating`'s rule with the hyperdirect drive at zero; writing it again in the runtime would leave the crate composed by nothing and the tie's rule in two places.
