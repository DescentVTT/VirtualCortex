# ADR-0086: The inhibitory baseline built — ADR-0085's parameter placed in the modulator section's reserved bytes as a flag byte at `[24]` and a Q16.16 value at `[28..32)`, the image format moved from 14 to 15, unset encoded as the zeros a format-14 writer left so that its record reads as unset while its header is refused as every foreign version is; the configuration takes it as an `Option`, the coordinator publishes a third modulation beside ADR-0068's two, and the fan-out picks it for every slot of an inhibitory block by the polarity it already reads; unset, every pinned number of the tree and the determinism pin stand bit for bit

## Context and Problem Statement

[ADR-0085](0085-inhibition-off-the-reward-gate.md) decided the rule and left its placement to this round: *"A new parameter, the inhibitory baseline: when it is set, every synapse of an inhibitory block consolidates under `clamp(inhibitory baseline, 0, 1)`, addressed or not — the dopamine term never reaches it — and every excitatory synapse under `Modulations::for_synapse` as today; when it is unset, every synapse consolidates as today. It changes what a run does, so it is part of the image (§8.3): the round places it in the modulator section's reserved bytes or elsewhere, moves the image format from 14 to 15, reads a format-14 image as unset, and updates §5.2's table and the changelog."* Brief 039's empowerment names the choices: where the parameter lives, how unset is encoded, whether the configuration takes an `Option`, and how the fan-out selects an inhibitory block's modulation — so long as unset is today's rule bit for bit, the hot path gains no allocation and no syscall, and the format moves to 15.

**What the engine did before this decision**, read for it (`runtime/cortex-runtime/src/executor.rs`, `image.rs`; `crates/cortex-connectome/src/lib.rs`). `Modulations` held two values, `addressed` and `at_rest`, both from `cortex-neuromod`'s `modulation` (`Modulations::of`, once per tick before the first barrier), published as two `AtomicI32` of `Shared` and read once per tick per worker in `phase_fan_out`; `for_synapse(addressed)` picked one per slot. The fan-out read a block's polarity from its presynaptic unit's flags (`Polarity::of_flags`, [ADR-0049](0049-dale-principle-in-plasticity.md)) and passed it to `step_stdp_all` and `consolidate_each`, which decide the half of the width and the pair rule; the polarity did not reach the modulation. The image's modulator section was one 64-byte record — the modulator's 16 bytes, the baseline at `[16..20)`, the inhibitory rule's target period at `[20..24)` ([ADR-0053](0053-the-waking-day-and-the-target-period.md)) and 40 reserved bytes that the loader refused unless zero (`ImageError::ReservedNotZero`). The header's `validate` refuses any version but `FORMAT_VERSION` (`HeaderError::ForeignVersion`; whitepaper rule L-6, [ADR-0007](0007-cortex-image-format.md)), so *"a format-14 image reads as unset"* cannot mean that the loader accepts a version-14 header: it means that the record's bytes a format-14 writer produced, under the version this decision stamps, decode as unset.

## Decision Drivers

- ADR-0085's rule as written, and its two conditions: unset is today's rule bit for bit, and the signal never reaches an inhibitory slot while it is set.
- `CLAUDE.md`: a change to a record's bytes, reserved ones included, moves `CortexFileHeader::version`, updates the record's table in whitepaper §5.2 and gets a changelog entry; a parameter that changes what a run does is part of the image (§8.3); the engine never amends it by itself (F-37: the behaviour gate admits no plasticity parameter).
- Principle 5: the loader refuses every byte the writer never produces, by name, and a test holds each refusal at its byte.
- [ADR-0023](0023-executor.md)'s hot path: no allocation, no syscall; the fan-out reads one more word per tick per worker and makes one more comparison per slot.
- [ADR-0030](0030-verification-governance.md): the rule over the lattice of `testkit/prop.rs`, every mutant in the changed lines caught, every pinned number of the tree and the determinism pin unchanged with the parameter unset.
- Latest ≠ Newest (§2.1): the mechanism is the rule ADR-0085 decided and nothing newer — no per-unit scaling, no second excitatory baseline, no reward predictor; no dependency, no tool.

## Considered Options

1. **Where the parameter lives**: the modulator section's reserved bytes; a section of its own; the homeostasis record's reserved bytes; a new record.
2. **How unset is encoded**: a flag byte and a value that is zero while unset; a sentinel value in the word alone (a value outside $[0, 1]$ meaning unset); a format-14 default read from the header's version.
3. **The configuration**: `Option<i32>`; a value with a sentinel.
4. **The fan-out's choice**: a third field of `Modulations` and `for_synapse(addressed, polarity)`; a branch in the fan-out around the existing two-value call; a per-unit flag beside `sources` and `targets`.
5. **The word between the coordinator and the workers**: one `AtomicI32` carrying the modulation while set and a value below zero while unset; an `AtomicI32` and an `AtomicBool`.

## Decision Outcome

**Options 1 (the modulator section's reserved bytes), 2 (a flag byte and a zero value), 3 (an `Option`), 4 (a third field, chosen by the polarity) and 5 (one word with a sentinel below zero).**

- **The rule in the executor** (`Modulations`, `runtime/cortex-runtime/src/executor.rs`). `Modulations` gains `inhibitory: Option<i32>`; `Modulations::of(modulator, baseline, inhibitory_baseline)` computes the first two as before and the third as `inhibitory_baseline.map(|b| b.clamp(0, MODULATION_ONE_Q16))`, the signal never entering it; `for_synapse(addressed, polarity)` returns the third for a slot of an inhibitory block while it is set and, otherwise, `addressed` or `at_rest` as before. Unset, the third is `None` and every slot's modulation is what it was, so every run before this decision is the run it was, bit for bit; the two previous values are not touched by the third (asserted over the lattice).
- **The configuration and the executor.** `Config::inhibitory_baseline_q16: Option<i32>`, default `None`; `Executor::new` refuses a set value outside $[0, 1]$ with `ConfigError::InhibitoryBaselineOutOfRange`, as it refuses the baseline. The executor holds the value beside `modulation_baseline_q16`, reads it back through `inhibitory_baseline_q16()` and takes the loader's through `set_inhibitory_baseline`, which refuses a set value outside $[0, 1]$ whole and leaves the value standing. `Shared` gains `modulation_inhibitory: AtomicI32`; `tick` publishes `inhibitory_word(modulations.inhibitory)` beside the two words of [ADR-0068](0068-the-reward-addressed.md) before the tick's first barrier; `phase_fan_out` reads it back through `inhibitory_of_word` and passes the polarity it already had to `for_synapse` for every slot. The word is the modulation itself while set — within $[0, 1]$, as `Modulations::of` clamps it — and `INHIBITORY_UNSET`, −1, while unset, a value no clamped modulation is; zero is set at zero and not the sentinel, which the tests hold at that edge.
- **The image** (`runtime/cortex-runtime/src/image.rs`; `crates/cortex-connectome/src/lib.rs`). The modulator section's `[24]` is the flag, `INHIBITORY_BASELINE_SET` (1) while set and zero while unset; `[28..32)` the value, an `i32` in Q16.16, zero while unset; `[25..28)` and `[32..64)` stay reserved, 35 bytes. `FORMAT_VERSION` moves from 14 to **15**, with its note in the version history. The loader refuses, by name: a reserved byte that is not zero, a flag of zero with a value that is not, and a flag that is neither zero nor one — bytes the writer never produces — as `ImageError::ReservedNotZero { section: 42, index: 0 }`; and a flag of one with a value outside $[0, 1]$ as `ImageError::Config(ConfigError::InhibitoryBaselineOutOfRange)`, the baseline's refusal. A flag of zero with a value of zero — the bytes a format-14 writer left — reads as unset. **A version-14 header is refused as every foreign version is** (`HeaderError::ForeignVersion(14)`), which L-6 requires and the brief's sentence did not override: what reads as unset is the record. The image's value, set or unset, outranks the configuration's (§8.3), as the baseline's does.
- **The tests.** `executor.rs`: `the_inhibitory_baseline_is_unset_by_default_and_refused_when_set_outside_the_unit_interval` (the default, the refusal at both edges by `new` and by the setter with the value standing, the edges accepted, set at zero distinct from unset, and the word the tick publishes at each) and, over the lattice of `testkit/prop.rs` and four thousand seeded triples of baseline, signal and inhibitory baseline, `an_inhibitory_block_consolidates_under_the_inhibitory_baseline_alone_while_it_is_set` (the third modulation the clamped inhibitory baseline whatever the addressing and the signal, the other two untouched, an excitatory slot's as before, an inhibitory slot's an excitatory slot's while unset, the word round-tripping with zero set and the sentinel unset, and the harness's case — the gate at zero, the inhibitory baseline 0.5, a reward, a punishment, a half and rest — the signal reaching the addressed excitatory slot and no inhibitory one); `consolidate_each_under_one_modulation_is_consolidate_all` unchanged. `tests/modulation.rs`: `an_inhibitory_synapse_consolidates_under_the_inhibitory_baseline_and_no_signal_reaches_it`, one synapse of each polarity onto one target — with the gate at zero and the inhibitory baseline at 0.5 the inhibitory synapse consolidates half its trace at every presynaptic spike with no reward, held to an oracle block consolidated under exactly 0.5, while the excitatory weight waits; a reward with every unit addressed consolidates the excitatory synapse nearly whole and leaves the inhibitory one under 0.5, not under the signal, which is shown to differ; a punishment leaves the excitatory weight where it was and the inhibitory one under 0.5, not under zero, shown to differ; the image carries 0.5 under a configuration that says unset and a loaded engine continues alike; and unset, the same pairings are today's rule — the inhibitory synapse waits under the gate, consolidates under the reward, and the image carries unset under a configuration that says 0.5. `tests/image.rs`: `the_inhibitory_baseline_is_written_to_and_read_from_the_image_and_a_record_left_zero_reads_as_unset` (unset writes zeros and reads as unset under a configuration that says 0.25; set writes the flag and the value and reads back under a configuration that says unset; set at 0, 1 LSB, 1.0 − 1 LSB and 1.0 read as set; −1, 1.0 + 1 LSB, `i32::MIN` and `i32::MAX` refused as the configuration's are; a flag of zero with a value that is not, a flag of 2 and of 255, and each of the reserved bytes 25, 26, 27, 32, 40 and 63 refused as bytes the writer never produces; a version-14 header refused as foreign); the existing reserved-byte case moved from `[24]`, now the flag, to `[25]`. `crates/cortex-connectome`: the version's two assertions read 15. `tests/differential.rs` and `tests/contention.rs`, whose configurations are spelled out field by field, name the field as `None`.
- **Every pinned number unchanged with the parameter unset.** The workspace's tests in the debug profile pass with the new tests among them, 625 passed and 49 ignored where ADR-0083 read 620 and 48 (the five tests above and the weekly test of brief 039); the determinism pin of [ADR-0030](0030-verification-governance.md) (`the_random_network_hashes_to_the_pinned_value_on_every_architecture`) is unmoved; the forty-eight `exhaustive` tests of the weekly job, every one built with the parameter unset, rerun in the dispatch [ADR-0087](0087-inhibition-off-the-reward-gate-measured.md) records. The whitepaper's determinism pin T-1 does not move: the parameter unset publishes a word the fan-out reads as none, and the block's bytes do not change.
- **The mutation gate** ([ADR-0030](0030-verification-governance.md)): every mutant `cargo-mutants` makes in the changed lines is caught, in CI, as [ADR-0087](0087-inhibition-off-the-reward-gate-measured.md)'s evidence records with the pull request.

### Consequences

- Good: ADR-0085's rule exists in the executor and the image, and unset it is today's rule bit for bit — the format moves for one flag byte and one word, every pinned number stands, and the sixteen tests of the mechanism hold its every edge.
- Good: the parameter is part of the image and outranks the configuration on load, so a run with it set is defined by its image (§8.3) and resumable from one; it is not a registry entry (F-37).
- Good: the hot path gains one atomic load per tick per worker and one match per slot, no allocation and no syscall; the workers read the three words the coordinator published before the barrier, as they read two.
- Neutral: the format is 15; a format-14 image is refused by its header as every foreign version is, and its record's bytes read as unset under the new version, which is what the version note says.
- Neutral: `Modulations::for_synapse` takes the polarity, so the one caller passes what it already read; the property test of ADR-0068 gained an argument and nothing else.
- Bad: the inhibitory baseline is a third number the tick publishes and the image carries for one rule read once; a fourth would want a table, not a fourth word.

## Alternatives considered and why rejected

- **A section of its own, or the homeostasis record's reserved bytes** (option 1): a parameter of the modulation belongs with the modulation state, beside the baseline it stands next to in the rule; a new section for four bytes would be a directory entry and a CRC for nothing.
- **A sentinel in the value alone** (option 2): a value outside $[0, 1]$ meaning unset makes the bytes the writer never produces and the bytes that mean unset the same bytes; a flag byte keeps the refusal of a stray value and the meaning of zero apart, and a format-14 record's zeros read as unset without a special case.
- **A format-14 default read from the header** (option 2): the loader refuses a foreign version and must keep refusing it (L-6); what is read is the record under the current version.
- **A value with a sentinel in the configuration** (option 3): an `Option` is the type of a parameter that may be unset, and the compiler holds the distinction where a sentinel would hold it in a comment.
- **A branch in the fan-out around the two-value call** (option 4): the choice is the modulation's and belongs in `Modulations`, where the lattice test reads it; a branch in the fan-out would be a rule outside the type that names it.
- **An `AtomicBool` beside the word** (option 5): two loads and a race between them for a value a sentinel below zero carries in one, which no clamped modulation collides with.
- **Inhibition off the gate always, with no parameter**: rejected by ADR-0085; every pinned run since ADR-0032 consolidated its inhibitory synapses under the shared modulation.
