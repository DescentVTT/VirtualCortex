### 1.1 矽基超越碳基的實體物理維度
生物大腦絕非神聖不可超越的計算裝置；它只是一部受限於新陳代謝上限（約 20W）、頭骨幾何限制（受限於產道，被迫擠壓成 3D 腦回摺疊）、化學擴散遲緩（$1 \sim 100\,\text{m/s}$ 軸突傳導）與發放率低下的碳基演化產物。

現代矽基架構在物理特性上具備四大實質超越優勢：
1. **傳導速度與時序抖動**：生物離子流傳輸速度僅 $20 \sim 100\,\text{m/s}$（毫秒級抖動）；現代 CPU / CXL 總線電信號傳播速度超過 $200,000\,\text{km/s}$，提供奈秒級的確定性響應。
2. **通訊資訊密度**：生物脈衝只有單純的二值（0/1）動作電位，需要靠低效的發放率編碼；矽基事件透過 **16 位元組定點數封包（`SpikeEnvelope`）**，在單次暫存器傳輸中直接交付衝擊權重、時序相位與發射端標籤。
3. **位元級跨平台完全確定性**：生物類比神經網路充滿隨機雜訊與漂移；VirtualCortex 藉由 **Q16.16 定點數運算**，消除浮點結合律破壞，確保在 x86_64 與 ARM64 上神經動態軌跡達到 100% 逐位元完全一致。
4. **狀態持久化與抗毀性**：生物突觸脆弱且不可逆死亡；矽基構造體支援 **零拷貝記憶體映射與 ACID 預寫日誌（WAL）快照**，支援毫秒級崩潰恢復。

### 不變量 1：位元級跨平台完全確定性 (Bit-Exact Determinism)
在高度並發的多執行緒工作竊取環境下，平行浮點加法不滿足結合律：
$$(a + b) + c \ne a + (b + c)$$
這會導致同一個 SNN 網路在不同 CPU 核心數、編譯器優化參數下產生完全發散的神經軌跡，徹底喪失在醫療控制與高精機器人中的可驗證性。  
**VirtualCortex 核心積分全域採用 Q16.16 定點數整數運算**（16 位元整數，16 位元小數；精度 $\approx 1.52 \times 10^{-5}\,\text{mV}$），確保脈衝流在 x86_64（AVX-512）與 ARM64（SVE2）上產生的神經演化結果具備 100% 逐位元完全一致性。

### 不變量 2：128-bit Tagged Pointer 與 ABA 免疫無鎖門控
神經元胞體無全域 Mutex 或 Read-Write 鎖。為徹底免疫無鎖鏈表高頻節點回收時的 **ABA 競爭條件**，信箱頭指標採用 **128-bit 複合原子結構**（`AtomicU128` 或 x86_64 `cmpxchg16b`）：
* 高 64 位：單調遞增世代計數器（Sequence Tag）。
* 低 64 位：記憶體鏈表頭指針（SpikeEnvelope Pointer）。

### 不變量 3：三級多尺度階層架構 (Three-Tier Multi-Scale Hierarchy)
拒絕「點神經元物理暴力窮舉」：
* **宏觀層（Macro-Scale）**：860,000 個微皮質柱（Hyper-Columns），以 Wilson-Cowan 連續平均場微積分方程式處理次閾值背景神經元群體，實時輸出 Theta/Gamma 腦電波。
* **介觀層（Meso-Scale）**：4,300 萬個多室錐體超節點（`DendriticSuperNeuron`），解耦頂樹突（預測反饋）與底樹突（感官前饋），以 NMDA 平台電位實現局部邏輯運算（$1 \approx 1,000$ 點神經元表達力）。
* **微觀層（Micro-Scale）**：高顯著性動作電位透過離散時間輪派發。

### 不變量 4：二級混合突觸拓撲 (Two-Tier Hybrid Connectome)
* **Tier-A（柱內局部超密連線，佔全腦 $\sim 90\%$）**：預先分配於連續的 **分塊 CSR（Chunked CSR）** 陣列中（每 Chunk 64 條突觸 = 512 位元組 = 8 個快取行），完全飽和 CPU 硬體預取器。
* **Tier-B（跨區長程稀疏連線，佔全腦 $\sim 10\%$）**：由 **3D 空間幾何核與低秩張量** 即時向量運算，僅在發生 STDP 塑性調整時將偏差寫入無鎖 **稀疏塑性差量表（$\Delta W$）**。

### 不變量 5：私有時間輪與雙緩衝分相步進 (Phased Epoch Barrier)
每個 Worker 執行緒維護獨立的私有時間輪（256 槽位，$\Delta t = 0.5\,\text{ms}$），徹底消滅跨核心鎖競爭。時鐘推進遵循確定性三相步進協議：
$$\text{Phase 1: 軸突事件倒出} \longrightarrow \text{Phase 2: 工作竊取並行積分} \longrightarrow \text{Phase 3: 原子屏障時脈遞增}$$

### 不變量 6：3D 連續化學調質體素場
多巴胺、乙醯膽鹼、血清素以三維擴散拉普拉斯算子在 $128 \times 128 \times 64$ 體素網格中連續演化，驅動 **三因子 STDP 強化學習**：
$$\Delta W_{ij} \propto e_{ij} \cdot \left([\text{DA}] - \text{DA}_{\text{base}}\right)$$

## 3. 核心子系統數據結構與硬體對齊規格

```rust
use core::sync::atomic::{AtomicU8, AtomicU64};

// 1. 多室樹突超節點 (嚴格 64 位元組對齊 POD 結構)
#[repr(C, align(64))]
pub struct DendriticSuperNeuron {
    // [0..8] 64-bit 打包層級 ID
    pub id: PackedId,

    // [8..24] 128-bit Tagged 無鎖信箱指標 (ABA 防護)
    pub mailbox_head_ptr: AtomicU64,    // 64-bit 脈衝鏈表頭指針
    pub mailbox_tag: AtomicU64,         // 64-bit 單調世代計數器

    // [24..40] Q16.16 定點數生物物理膜電位 (16 bytes)
    pub v_soma: i32,                    // 胞體電位 (Q16.16 mV)
    pub v_basal: i32,                   // 底樹突前饋感官電位 (Q16.16 mV)
    pub v_apical: i32,                  // 頂樹突背景反饋電位 (Q16.16 mV)
    pub v_thresh: i32,                  // 自適應發放閾值 (Q16.16 mV)

    // [40..48] 時序不變量與 NMDA 平台狀態 (8 bytes)
    pub nmda_plateau_ticks: u16,        // NMDA 平台電位剩餘滴答數
    pub refractory_ticks: u16,          // 絕對不反應期倒數
    pub last_spike_tick: u32,           // 上次動作電位發放滴答

    // [48..56] 連通拓撲與空間幾何座標 (8 bytes)
    pub local_synapse_chunk: u32,       // Tier-A 柱內連續 CSR 索引
    pub plastic_delta_head: u16,        // Tier-B 跨區稀疏差量表索引
    pub spatial_coords_packed: u16,     // 柱內量子化 3D 空間座標

    // [56..58] 並發門控狀態機與旗標 (2 bytes)
    pub gate_state: AtomicU8,           // 0=IDLE, 1=QUEUED, 2=RUNNING, 3=RECHECK
    pub flags: u8,                      // bit0: 暴發放電, bit1: 抑制性, bit2: 塑性凍結

    // [58..64] 保留對齊填充，精確對齊 64 位元組 (6 bytes)
    pub _reserved: [u8; 6],
}

// 編譯期靜態斷言，確保無跨快取行偽共享
const _: () = {
    assert!(core::mem::size_of::<DendriticSuperNeuron>() == 64);
    assert!(core::mem::align_of::<DendriticSuperNeuron>() == 64);
};
```

## 6. 可觀測性、遙測與故障邊界 (Observability & Resilience)

在 2026+ 系統標準中，無法觀測的系統無法投入生產：

### 6.1 零開銷 eBPF 與 SPSC 遙測環
* 核心運算 Worker 不執行任何格式化日誌輸出。事件摘要寫入無鎖 SPSC 環形通道。
* 背景遙測執行緒批次讀取並即時導出：
  - **Perfetto / Chrome Tracing 格式** 的微秒級脈衝頻譜圖。
  - **局部場電位（LFP）功率譜**（Theta/Gamma 頻段比）。
  - **記憶體總線頻寬飽和度監控**。

### 6.2 柱級崩潰隔離 (Column Panic Isolation)
* 執行緒邊界封裝在「微皮質柱」層級。
* 若某一神經核團因突觸數值溢出產生異常，系統僅重置該柱之膜電位為靜息電位並記錄追蹤日誌，**絕不引發整台伺服器崩潰中斷**。

這是一套具備工業級韌性、數學可重現性與硬體親和性的新世代超高密度神經擬態協同處理器架構。
